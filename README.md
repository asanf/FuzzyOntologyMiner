# FuzzyOntologyMiner
Java library able to extract fuzzy concepts from a collection of unstructured text and organize them into a fuzzy ontology.

This library was initially developed as a project for the Semantic Web course at the University of Salerno. The repository contains an essay produced for the course in Italian, currently no english verion available. 

## Dependencies
This software make use of 
- [OWL API](http://owlcs.github.io/owlapi/) 
- [Stanford POS Tagger](http://nlp.stanford.edu/software/tagger.shtml)
